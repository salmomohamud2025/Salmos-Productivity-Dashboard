# Personal Productivity Dashboard

A custom-built productivity dashboard designed to bring everyday tools, reminders, and information together in one interface.

## Project Overview

I independently designed and developed this personal productivity dashboard using Python and web technologies. The project focuses on building a practical application that combines local data storage, user authentication, email integration, and secure remote access.

The dashboard runs on Ubuntu Linux and can be accessed from multiple devices through a private network.

## Technologies Used

- **Python** — Backend development and application logic
- **HTML, CSS, JavaScript** — Dashboard interface
- **JSON** — Local data storage
- **Gmail IMAP** — Email integration
- **Tailscale** — Private network access across devices
- **Ubuntu Linux** — Development and runtime environment
- **systemd** — Background service and automatic startup

## Technical Features

- Custom web-based dashboard
- Local data persistence
- Password-protected access
- Gmail integration
- Background processes and notifications
- Remote access through a private network
- Automatic startup using Linux system services
- Desktop application shortcut

## Engineering Challenges

During development, I worked through several practical technical challenges:

- Configuring Gmail authentication securely.
- Troubleshooting remote access between devices.
- Resolving browser security and login issues.
- Configuring Tailscale networking.
- Setting up a persistent background service on Ubuntu.
- Creating an application shortcut and startup process.

## Privacy and Security

This public repository documents the project without exposing the private working environment.

Personal information, credentials, authentication files, and private dashboard data are intentionally excluded.
